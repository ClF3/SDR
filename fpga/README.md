# FPGA

AC920 PL source tree.

Recommended contents:

- `rtl/`: synthesizable RTL modules
- `tb/`: simulation testbenches
- `constraints/`: board and FMC constraints
- `vivado/scripts/`: reproducible Vivado project/build scripts
- `vivado/ip_repo/`: checked-in custom IP metadata when required
- `artifacts/`: optional release artifacts, kept mostly out of git
